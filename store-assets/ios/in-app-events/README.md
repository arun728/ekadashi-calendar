# In-App Events

Reusable every year: the copy and art have no year or date. Only the event
window is set in App Store Connect each year, from that year's published dates
(the IST dates in `assets/calendar/<year>.json`). Smarta and Vaishnava dates can
differ by a day and other time zones can fall a day earlier, so each window opens
a few days before the Ekadashi.

Dates for the first season: Nirjala 14 Jun 2027, Devshayani 14 Jul 2027,
Prabodhini 10 Nov 2027, Mokshada 9 Dec 2027.

Artwork is text-free, as Apple recommends: the App Store overlays the event name
and descriptions, blurs the bottom of the card and adds its own gradient, so key
art sits in the upper middle. Use App Store Connect's preview to confirm nothing
important is hidden.

Vaikuntha Ekadashi (Margazhi) is added once the app ships the following year's dates.

Apple allows up to 10 approved events at a time; each can run up to 31 days.
