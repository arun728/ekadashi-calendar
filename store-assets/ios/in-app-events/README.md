# In-App Events (2027)

Artwork is text-free, as Apple recommends: the App Store overlays the event name and descriptions, blurs the bottom of the card and adds its own gradient, so key art sits in the upper middle. Use App Store Connect's preview to confirm nothing important is hidden.

Dates are the published IST dates in `assets/calendar/2027.json`. Smarta and Vaishnava dates can differ by a day and other time zones can fall a day earlier, so each window opens a few days before.

Vaikuntha Ekadashi (Margazhi) falls in early January 2028, outside the app's 2027 data, so December uses Mokshada Ekadashi and Gita Jayanti. Add a Vaikuntha event once 2028 dates ship.

Apple allows up to 10 approved events at a time; each can run up to 31 days.
